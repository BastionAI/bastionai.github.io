Memory

Knowledge engine

  1. Read PDFs, web pages and text — scanned pages via on-device OCR
  2. Chunk into passages, page by page
  3. Embed each passage with MiniLM on Core ML
  4. Index in a libSQL vector database (cosine, top-k) + FTS5 full-text
  5. Rank with hybrid keyword + semantic scoring

Agent

Bastion Harness

  • RouterSmall file? Read it whole. Big library? Hybrid search. Needs an action? Tools.

  • Tool runtimeDocuments · Calculator · Web (opt-in) · MCP servers.

FAQ

Questions, answered.

Does it need an internet connection?

Only once, to download a model. After that, chatting, documents, summaries and voice all work offline. Web search is optional and off by default.

Is any of my data collected?

No. Your documents and conversations are processed and stored on your device. BastionChat’s App Store privacy label is “Data Not Collected”.

Can I lock the app with Face ID?

Yes. On iPhone and iPad, touch and hold the BastionChat icon and choose Require Face ID — the app then opens only with Face ID or Touch ID, and its content stays hidden from notifications and search.

Which devices are supported?

iPhone and iPad with iOS / iPadOS 18 or later, and Macs with Apple silicon. Newer devices with more memory can run larger, smarter models.

How much does it cost?

$9.99, once. No subscription, no usage limits, and Family Sharing for up to six people.

How accurate are the answers?

On-device models are fast and capable, but like any AI they can make mistakes. That’s why every document answer links back to its source, so you can check it in one tap.

Which languages does the app support?

English, French, German, Spanish, Italian, Portuguese, Japanese and Korean.
